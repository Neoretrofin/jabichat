# jabichat 🐸 - Project Guidelines

## Описание проекта
Мы разрабатываем серверлес-мессенджер (PWA) с полностью децентрализованной архитектурой.
Никаких серверов и баз данных. Только P2P и Nostr.

## Стек технологий
- Frontend: React + TypeScript + Vite.
- UI: Tailwind CSS + Lucide React.
- База/Сигналинг: @nostr-dev-kit/ndk (сеть Nostr, публичные реле).
- Шифрование сообщений: NIP-44 или NIP-17.
- Звонки/Экран: WebRTC (SDP обменивается через Nostr Ephemeral Events).
- Стейт: Zustand.

## Дизайн-система (Toad Theme 🐸)
Всегда используй эту стилистику при создании компонентов:
- Формы: Максимальное скругление (`rounded-2xl`, `rounded-full`), чтобы элементы напоминали листья кувшинок (lily pads).
- Цвета: 
  - `swamp-dark` (фон): #1e293b или #1c2e26
  - `lily-green` (сообщения): #4ade80 или #86efac
  - `frog-skin` (кнопки): #22c55e
  - `mud-brown` (акценты): #78350f
- Настроение: Уютное, болотное, милое (swampcore).

## Архитектурные правила
1. Всегда пиши строгий TypeScript, не используй `any`.
2. Разбивай компоненты на мелкие модули (отдельно кнопки, аватарки, экраны).
3. Приватный ключ (`nsec`) должен сохраняться безопасно и не должен покидать устройство.
4. Перед изменением логики WebRTC или NDK обязательно продумай краевые случаи (офлайн, отказ реле).
